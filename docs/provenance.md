## Boundaries

The Python code is a small standard-library example. It does not implement a general spreadsheet engine, an ML pipeline, an autonomous operations system, or a production validation service. API and Zapier familiarity are stated as background; no integration is demonstrated.

No private project names, internal architecture, private prompts, source code, documents, credentials, customer records, or employer data are included. Tooling and publication references in the documentation are real external sources; the operational examples themselves are synthetic.

Before presenting this as a work sample, the maintainer should be able to explain each decision, reproduce the checks, and distinguish assisted preparation from independently performed work. Contributions should preserve that distinction.
